# Multiplayer task-card template

Instantiate one bounded multiplayer risk at a time:

```text
MULTI-01-INPUT-TOPOLOGY
MULTI-02-JOIN-CREDITS-CONTINUE
MULTI-03-MULTI-ACTOR-CAMERA
MULTI-04-MULTI-COLLISION-COMBAT
MULTI-05-RESOURCE-PEAK
MULTI-06-PHYSICAL-SOAK
```

P2 HUD presentation is a regression lock, not P2 gameplay or topology proof.
Each card declares exact pads/ports/multitap topology, player identity and join
state, measured source behavior, resource/timing budgets, deterministic repeat,
missing/reordered-controller control, exact image/readback, and physical
evidence boundary. Subjective multiplayer readability or feel requires an
explicit USER_REVIEW card.
