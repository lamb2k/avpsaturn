# Character-expansion task-card template

Instantiate after ORACLE-02 and ORACLE-03 bind measured differences for one
remaining character.

```text
CHAR-<id>-ASSETS
CHAR-<id>-ACTIONS
CHAR-<id>-COLLISION
CHAR-<id>-HUD-AUDIO
CHAR-<id>-ENDING
CHAR-<id>-FULL-ROUTE
USER-<id>-REVIEW
```

Every card uses the common player runtime and `PortV2CharacterDef`; copied
player engines are prohibited. Each matrix cell must be `MEASURED`,
`ADAPTED`, or `UNKNOWN`. Require focused differentials, deterministic
repeat, real negative control, exact Saturn diagnostic/readback, approved locks,
full-route acceptance, and physical proof for any new workload class.
