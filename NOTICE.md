AvP Saturn is a software preservation project. It brings Capcom's Alien vs. Predator
(CPS2 arcade, 1994) to the Sega Saturn as native code.

Alien vs. Predator, its code, graphics, audio, characters, and related marks
belong to their respective owners, as does the bonus character Wolverine. The
rights-holder review for publishing this project and its beta disc is done
(owner, 2026-11-14).

This repository does not include the Alien vs. Predator ROM files, raw captures
or memory dumps. It holds conversion code, data derived from the game, and the
release media under `docs/images/release/` and `docs/media/`. The beta disc image
is published only as a release download. Build only from a ROM set you are
authorized to use.

## Licence (owner decision, 2026-11-08)

This repository has no open-source licence. It holds code and data derived from Alien vs. Predator, which belong to the rights holders, so it cannot be offered under one. That includes the lifted game logic, generated tables, prototype binaries and the cover art's subject. The project's original, game-neutral tooling is published separately under MIT in [lamb2k/cps2saturn](https://github.com/lamb2k/cps2saturn).
