This repository is a private technical prototype. It contains conversion code
but does not include the required Alien vs. Predator ROM files, generated game
assets, captures, or disc images. Those local artifacts are ignored.

Alien vs. Predator, its code, graphics, audio, characters, and related marks
belong to their respective owners. Use only source material you are authorized
to use. Do not distribute this private build or promote it publicly without an
explicit licensing and rights-holder review.

## Licence (owner decision, 2026-11-08)

This repository has no open-source licence. It holds code and data derived from Alien vs. Predator, which belong to the rights holders, so it cannot be offered under one. That includes the lifted game logic, generated tables, prototype binaries and the cover art's subject. The project's original, game-neutral tooling is published separately under MIT in [lamb2k/cps2saturn](https://github.com/lamb2k/cps2saturn).

This project is intended for software preservation. Going public is planned to coincide with the AvP Saturn release, after the rights-holder review described above.
